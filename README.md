# Sul na Urna — simulador de votação v3

Atualização sobre a versão enviada pela usuária.

## Alterações desta versão

- seção apresentada como versão pública do Simulador de Votação, sem texto de “aprovação da interface”;
- urna redesenhada para uma aparência física mais próxima dos modelos atuais, mantendo identidade própria do Sul na Urna;
- som curto ao confirmar cada cargo, gerado no navegador via Web Audio API;
- sequência sonora mais longa na confirmação do último cargo, seguida da tela FIM;
- tela intermediária “VOTO CONFIRMADO” entre cargos;
- botão “Recomeçar simulação / Simular novamente” maior e mais destacado;
- permanece sem gravação de votos no Supabase/Admin nesta etapa;
- Federal e Estadual usam a base atual; Senado, Governador e Presidente continuam aguardando carga da nova base completa.

## Arquivos alterados

- `index.html`
- `css/simulator.css`
- `js/simulator.js`

Nenhum arquivo de schema, seed ou banco foi alterado.
